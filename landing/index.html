🔑 Gmail app password

Saviour reads your bank's transaction emails. To do that securely, Google issues a one-time 16-character "app password" — separate from your real Gmail password. You can revoke it any time.

How to get one (~2 min):

  1. Click the button below to open Google's page in a new tab.
  2. If 2-Step Verification isn't on yet, turn it on first (Google guides you).
  3. Type Saviour as the app name, click Create.
  4. Copy the 16-character password Google shows you.

You're all set!

Two terminal commands and you're done.

Step A — download the installer

Step B — run it in Terminal

Open Terminal (Cmd+Space → "Terminal" → Enter), then paste:

bash ~/Downloads/saviour-install.sh

Takes 3-5 minutes the first time. The terminal will look frozen during pip install — that's fine, just let it run.

Step C — open the dashboard

Once it says "Saviour is installed!", run:

cd ~/saviour && python3 src/app.py

Then visit http://localhost:5001 in your browser.

📘 First-time tip: when the dashboard loads, a quick guided tour will walk you through the main features. You can replay it any time by clicking 📘 Guide in the top bar.
